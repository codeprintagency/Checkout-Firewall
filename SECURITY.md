# Security policy

Please report suspected Checkout Firewall vulnerabilities privately. Use GitHub's private **Report a vulnerability** workflow when available, or email [jacob@codeprint.io](mailto:jacob@codeprint.io). Do not include exploit details in a public issue.

Include the affected version, WordPress/WooCommerce/PHP versions, checkout surface, a concise impact statement, and safe reproduction steps using synthetic data.

Never send card numbers, CVCs, gateway payloads, customer records, production database exports, cookies, passwords, secret keys, tokens, or license keys. Test only systems you own or are authorized to test. Do not perform denial of service, destructive actions, persistence, social engineering, privacy violations, or real payment transactions.

The current security-review target is the exact Free 1.0.0 candidate identified in the repository README. After public release, the latest maintained release line will receive security fixes.

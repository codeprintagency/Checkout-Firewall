# Contributing

Focused bug reports and pull requests for the Checkout Firewall Free source are welcome.

Before opening an issue:

1. Confirm the behavior against the newest public Free source.
2. Record WordPress, WooCommerce, PHP, plugin, checkout-surface, and gateway versions.
3. Use synthetic data and the smallest safe reproduction.
4. Remove customer, store, order, credential, payment, and license information.

Use GitHub Issues only for non-sensitive reports. Follow `SECURITY.md` for suspected vulnerabilities.

Pull requests should be narrowly scoped, preserve the no-card-data and fail-open boundaries, use WordPress APIs and coding conventions, and include evidence for behavior or compatibility claims. Premium implementation work is maintained separately and is outside this repository.
